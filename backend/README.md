# Inventory & Order Management System (Java 17)

A beginner-friendly REST API backend built with Java 17, Spring Boot, Spring Data JPA, Hibernate, Bean Validation, and MySQL.

## Features
- Product CRUD and name search
- Stock adjustments and low-stock list (quantity <= 5)
- Order creation with server-side price calculation
- Automatic stock deduction
- Order cancellation restores stock once
- Dashboard summary
- Validation and centralized error responses
- Database row locking during stock/order changes

## Requirements
- JDK 17
- Maven 3.9+ (or use the Maven wrapper generated by your IDE)
- MySQL 8+

## Setup
1. Create a MySQL user/database or let the configured URL create `inventory_db`.
2. Open `src/main/resources/application.properties`.
3. Set `spring.datasource.username` and `spring.datasource.password`.
4. From this folder run:
   ```bash
   mvn spring-boot:run
   ```
5. API base URL: `http://localhost:8080/api`

Hibernate `ddl-auto=update` creates/updates tables for local development. Do not use it as a production migration strategy.

## API list

### Products
- `POST /api/products`
- `GET /api/products`
- `GET /api/products?name=key`
- `GET /api/products/{id}`
- `PUT /api/products/{id}`
- `DELETE /api/products/{id}` (soft-deletes products that have appeared in an order; otherwise deletes them)
- `PATCH /api/products/{id}/stock`
- `GET /api/products/low-stock`

### Orders
- `POST /api/orders`
- `GET /api/orders`
- `GET /api/orders/{id}`
- `PATCH /api/orders/{id}/status`

Allowed statuses: `PLACED`, `COMPLETED`, `CANCELLED`. Only `PLACED` orders can transition to `COMPLETED` or `CANCELLED`.

### Dashboard
- `GET /api/dashboard/summary`

## Example requests

Create a product (`POST /api/products`):
```json
{
  "name": "Keyboard",
  "category": "Electronics",
  "price": 800.00,
  "quantity": 20
}
```

Create an order (`POST /api/orders`):
```json
{
  "customerName": "Rahul",
  "items": [
    { "productId": 1, "quantity": 2 }
  ]
}
```

Cancel an order (`PATCH /api/orders/1/status`):
```json
{ "status": "CANCELLED" }
```

Stock adjustment (`PATCH /api/products/1/stock`):
```json
{ "change": 10 }
```

## Important notes
- This is the core backend. Authentication/JWT and the React frontend are not included yet.
- For production, add authentication/authorization, database migrations, audit logging, and integration tests.
- Use Postman to test the endpoints.
